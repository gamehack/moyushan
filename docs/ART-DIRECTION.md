# 摸鱼山 V2 美术方向：自然主义半写实苏州园林

## 核心原则
风景是主角，非宗教、不做任务。参考拙政园、留园、网师园的空间语言，不声称真实复刻。
以白墙黛瓦、木梁、回廊、漏窗、月洞门、临水茶亭、山石、竹影、池水构成移步换景。

## 第一屏「临水茶亭」
- 前景：自然岸石、疏密合理的植被；中景：有结构和比例的茶亭与池水；远景：景墙、漏窗和借景树冠。
- 建筑要有真实屋脊/瓦面/檐口/柱梁逻辑，禁止浮空和屋面互穿。
- 太湖石重视瘦皱漏透；未取得相应模型时不能用普通多面体石块冒充。
- PBR 材质统一尺度，木/瓦/灰泥/岩石有粗糙度和法线细节。光照以柔和日光为主。
- 画面拒绝塑料高光、重复圆锥树、卡通块面、过饱和以及巨量空白天空或围墙。

## 验收
PC Chromium 第一优先；必须真实截图、旋转和近景观察。目标 60FPS、P95 <= 16.7ms，属于待测性能目标而非当前结果。
